# 群聊智能巡视 (astrbot_plugin_group_watch)

让群里的机器人像真人一样「会看眼色」主动接话。平时群友闲聊私事、吵架互怼时保持安静；遇到公开话题、求助探讨或提到自己时自然大方搭腔。

---

## 💡 它是怎么工作的？

```text
群友说话 ──> 短句防抖合并 ──> 便宜小模型判断语境 ──> 适合接话 ──> 唤醒主模型大方发言
                                      │
                                      └── 群友私聊/不适合 ──> 保持安静，记录至看板
```

1. **便宜小模型看场，主模型发言（极度省钱）**：
   平时用极低成本的轻量模型（如 Qwen2.5-7B、DeepSeek Flash、Gemini Flash）在后台默默评估语境；只有真正需要接话时，才唤醒昂贵的主模型生成回复。
2. **群友私聊一票否决（绝不瞎插嘴）**：
   小模型智能辨析发言对象。只要判定是两位群友在互相争论、私下对话，无论打分多高，**一票否决坚决不插话**。
3. **指令与噪声自动过滤**：
   管理指令（如 `/reset`、`/gw` 等）自动忽略，不污染日常闲聊语境，杜绝模型看串行或误把指令当聊天。
4. **多轮对话跟进**：
   机器人发言或被 `@` 后自动进入跟进状态，优先承接群友追问；话题自然结束或连续无关消息后自动退回静默。
5. **随时叫它闭嘴**：
   群友直接发送「`@机器人 闭嘴`」或「`@机器人 闭嘴 30`」（支持指定分钟/小时）立即进入静默期；后续只要显式 `@机器人` 提问即可随时唤醒。
6. **可视化监控看板**：
   内置独立网页看板，实时查看每条消息的评分、判断理由、为什么接话或为什么否决，数据一目了然。

## 📥 安装与生效

- **WebUI 安装（推荐）**：在 AstrBot 管理面板的「插件」页面，点击「安装插件」，粘贴本仓库 GitHub 地址即可。
- **手动安装**：直接克隆到 `data/plugins/` 目录：
  ```bash
  git clone https://github.com/R0smonti3/astrbot_plugin_group_watch.git
  ```
  安装或重载后立即后台生效。

## 🎮 常用指令

| 指令 | 作用说明 |
| :--- | :--- |
| `/gw status` | 查看当前群的巡视状态、跟进倒计时与最新判断理由 |
| `/gw on` / `/gw off` | 临时开启或暂停当前群的巡视功能 |
| `/gw silence [分钟数]` | 强制静默指定时间（如 `/gw silence 30` 静默半小时，`/gw silence 0` 解除） |
| `/gw ban <用户ID>` | 将指定用户加入黑名单（其发言直接忽略，不触发评估） |
| `/gw unban <用户ID>` | 将指定用户移出黑名单 |
| `/gw banlist` | 查看当前群的黑名单列表 |

> 💡 **群友免指令闭嘴**：群友直接发「`@机器人 闭嘴 30`」即可让机器人安静 30 分钟；再次 `@机器人` 问问题就能解除。

## ⚙️ 核心配置说明

在 AstrBot WebUI 插件配置中即可直接调整：

| 配置项 | 默认值 | 大白话说明 |
| :--- | :---: | :--- |
| `reply_willingness` | `3` | **接话积极度**（1:极保守≥85分，2:较保守≥70分，3:适中≥55分，4:积极≥42分，5:话痨≥30分） |
| `judge_provider_id` | 留空 | **评估模型选择器**。留空默认使用当前主模型；强烈建议下拉选择低成本的小模型专门看场 |
| `wake_words` | `[]` | **关注称谓/别名**。群友提到这些词时会加权评估（如机器人的外号） |
| `web_token` | 空 | **看板访问密码**。公网部署时建议填写，保护群聊看板隐私 |
| `follow_enabled` | `true` | **多轮连续互动**。开启后机器人回答完会持续跟进该群友的追问 |
| `repeat_trigger_count`| `3` | **人类本质复读机**。群友连续复读几句时机器人自动跟读（设为 0 关闭） |
