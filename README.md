# astrbot_plugin_group_watch (群聊智能巡视)

本插件为 AstrBot 提供群聊语境感知与主动接话能力。通过轻量语言模型分析群聊上下文与发言对象，在适宜时机自然参与群聊搭腔，同时避免打扰群友私聊或盲目抢话。

---

## 💡 基本运行逻辑

```text
群聊产生新消息 ──> 防抖合并短句 ──> 轻量模型评估语境 ──> 达到积极度门槛 ──> 唤醒主模型回复
                                          │
                                          └── 未达门槛 ──> 保持安静，记录至看板
```

1. **两阶段分层判定**：新消息先由响应快、成本低的轻量模型（如 Qwen2.5-7B、DeepSeek Flash、Gemini Flash 等）分析语境与发言对象，达标后再唤醒主模型生成回复，兼顾交互体验与调用成本。
2. **发言对象辨析**：
   * **群友私聊**：两名群友互相讨论私人事务或日常问候时，自动压低评分保持安静；
   * **代词指代**：准确识别“你”是指向其他群友还是指向机器人，避免误判；
   * **公开话题**：群友发起的公共讨论或提问，机器人可在适宜契机自然搭话。
3. **多轮对话跟进**：被 `@` 或主动接话后自动进入跟进状态，优先承接后续多轮互动；话题结束或连续多条无关消息时自动退出。
4. **关注关键词加权**：支持配置关注词列表，命中时由模型结合语境甄别是呼唤机器人还是在聊他人外号。
5. **可调指令静默**：群友发送“`@机器人 闭嘴`”或“`@机器人 闭嘴 30`”（支持指定分钟数或小时数）即可进入静默期，静默状态持久化保存，再次被显式 `@` 提问可随时提前解除。
6. **消息防抖与复读**：短时间内连续短句自动合并评估；群友连续排队复读时自动原样跟读。
7. **可视化看板**：提供内置网页看板查看实时状态与判断记录，支持访问令牌（Token）保护。

## 📥 安装方式

### 方式一：管理面板安装（推荐）
在 AstrBot 管理面板的「插件」页面，点击「安装插件」，粘贴本仓库的 GitHub 地址即可完成安装。

### 方式二：手动安装
进入 AstrBot 目录下的 `data/plugins/` 目录，执行以下命令克隆本仓库并重启 AstrBot：
```bash
git clone https://github.com/R0smonti3/astrbot_plugin_group_watch.git
```

## ⚙️ 配置项说明

所有选项均可在 AstrBot 管理面板中直观调整，或通过配置文件配置。以下为各配置项的默认值与说明：

| 配置项 | 类型 | 默认值 | 可调范围 / 格式 | 说明 |
| :--- | :---: | :---: | :---: | :--- |
| `enabled` | 布尔值 | `true` | `true` / `false` | 插件运行总开关。 |
| `web_token` | 字符串 | `""` | 任意文本 | 看板访问保护令牌。留空时不校验，配置后访问看板需验证 Token。 |
| `groups` | 列表 | `[]` | 会话 UMO 或群号 | 生效群聊列表。留空时对所有群聊生效。 |
| `wake_words` | 列表 | `[]` | 文本列表 | 关注关键词列表。出现时提高评估权重并结合语境甄别。 |
| `judge_enabled` | 布尔值 | `true` | `true` / `false` | 是否开启轻量模型的主动接话评估。 |
| `judge_provider_id` | 字符串 | `""` (留空) | 模型提供商下拉列表 | 动态模型选择器。留空默认直接使用主程序当前会话的主模型；也可下拉自选低成本小模型 |
| `judge_context_count` | 整数 | `8` | `5 ~ 30` 条 | 评估时参考的历史上下文消息数量。 |
| `reply_willingness` | 整数 | `3` | `1 ~ 5` 档 | 主动接话积极度（1:极保守≥85分，2:较保守≥70分，3:适中≥55分，4:积极≥42分，5:活跃≥30分）。 |
| `follow_enabled` | 布尔值 | `true` | `true` / `false` | 是否开启多轮对话跟进。关闭后每次交互均作单轮处理。 |
| `follow_score_bonus` | 整数 | `20` | `0 ~ 40` 分 | 多轮跟进状态下原互动对象发言的附加倾斜分值。 |
| `follow_max_minutes` | 整数 | `10` | `5 ~ 120` 分钟 | 机器人发言后维持跟进状态的最大时长。 |
| `follow_exit_unrelated` | 整数 | `5` | `2 ~ 20` 条 | 跟进期间连续出现多少条无关消息后自动退出跟进。 |
| `debounce_seconds` | 整数 | `3` | `0 ~ 15` 秒 | 消息防抖缓冲秒数，自动合并短时间内的连续发言。 |
| `silence_duration_minutes` | 整数 | `10` | `1 ~ 720` 分钟 | 收到“闭嘴”指令时未指定时长情况下的默认静默维持分钟数。 |
| `repeat_trigger_count` | 整数 | `3` | `0 ~ 10` 次 | 群友连续发送同一句话达到该次数时自动跟读（0 表示关闭）。 |
| `image_memory` | 布尔值 | `true` | `true` / `false` | 是否在处理图片时生成文字摘要存入语境缓存。 |
| `image_summary_chars` | 整数 | `200` | `60 ~ 500` 字 | 单张图片摘要文字的最大截断长度。 |
| `judge_system_prompt` | 文本 | (预设提示词) | 提示词模板 | 传递给轻量评估模型的系统提示词模板。 |

## 🎮 群聊指令

群管理员可在群聊中发送以下指令控制插件：

| 指令 | 作用说明 |
| :--- | :--- |
| `/gw status` | 查看当前群聊的巡视状态、缓存条数、跟进/静默倒计时及最新判断记录。 |
| `/gw now` | 立即对当前群聊上下文进行一次语境评估并返回判断结论与得分。 |
| `/gw on` | 临时开启群聊巡视（仅本次运行有效）。 |
| `/gw off` | 临时暂停群聊巡视（仅本次运行有效）。 |
| `/gw silence [分钟数]` | 让机器人进入指定时长的静默期（如 `/gw silence 30` 静默半小时，`/gw silence 0` 解除静默）。 |

> **提示**：普通群友也可以直接发送“`@机器人 闭嘴 30`”或“`@机器人 闭嘴 1小时`”触发自定义时长的静默；再次显式 `@机器人` 提问可提前解除静默。

## ⚠️ 注意事项与免责声明

1. **内容生成免责**：本插件仅负责群聊语境的评估调度与消息路由触发，最终发送的对话内容均由用户配置的大语言模型实时生成，不代表本插件及开发者的观点或立场。
2. **合规使用提示**：使用本插件时请遵守当地法律法规及即时通讯平台规范，切勿利用主动接话功能进行刷屏骚扰或散布不良信息。
3. **公网安全建议**：若将 AstrBot 部署在公网服务器上，建议在配置中设置 `web_token`（访问令牌），避免监控看板中的群聊记录被未授权访问。
